# Results: SrCu2SnS4

Processed outputs from the completed first-pass workflow:

- `workflow_summary.md`: parameters, gap, and best sampled power-factor table
- `transport_full.csv`: all 98 temperature/doping combinations
- `transport_best_power_factor.csv`: best sampled point by temperature and
  carrier type

`electronic_zT_no_lattice` is an upper bound using electronic thermal
conductivity only. Do not report it as full zT without lattice thermal
conductivity.
