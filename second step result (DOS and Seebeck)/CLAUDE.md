# Rules for this result package

This directory is the tidy second-step deliverable (QE-vs-BoltzTraP2 DOS
comparison and the Seebeck-vs-mu graph for SrCu2SnS4). It is a curated copy for
presentation, built from the authoritative records in
`thermo_candidates/SrCu2SnS4/`.

- `READY_TO_ATTACH/` is **frozen**: it was sent as Folder 1 of the combined
  email (drafted in the third-step package). It records exactly what was sent;
  do not edit it.

- The authoritative raw/derived records live in the material workspace; treat
  the copies here as read-only snapshots. If a number changes upstream,
  regenerate here rather than editing the copy.
- `WORKLOG.md` is append-only history. Add new dated entries; do not rewrite past
  ones.
- Do not add large raw files (wavefunctions, charge density, `.bt2`, full logs).
- No dates in any file that might be sent to Roy; dates belong only in the log.
- Keep units in every data-column header.
