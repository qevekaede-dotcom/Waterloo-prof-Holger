## 接手者如何确认发布提交

本文件不能嵌入包含自身的 Git 提交哈希。使用：

```bash
git fetch origin
git log -1 --format='%H %s' origin/main -- CLAUDE_HANDOFF
git merge-base --is-ancestor 712602c9fb1b6d8414b9e5cc34256a3978d6f275 origin/main
git ls-remote --heads origin main
```

预期 main 包含研究检查点和本交接提交。实际推送结果及精确发布提交由本次任务最终回复记录；若 push 因保护规则或并发更新被拒绝，必须明确报告，而不能把仅本地提交说成已发布。
