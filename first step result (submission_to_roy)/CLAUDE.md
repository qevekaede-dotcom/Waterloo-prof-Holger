# Roy-submission rules for Claude

This directory preserves the SrCu2SnS4 progress package that was sent to Roy.

- `READY_TO_ATTACH/` is frozen and must contain only the three sent attachments.
- `reproducibility/` contains the editable source material used to build the ZIP.
- `EMAIL_DRAFT.md` is a historical draft; do not assume it is the exact sent
  message.
- `create_results_excel.py` rebuilds the workbook from the authoritative CSV
  results.

Do not replace the sent workbook with another copy merely because the hashes
differ. The sent workbook was opened and repaired/resaved by Microsoft Excel.
Any future submission should be built in a new clearly named directory rather
than modifying this record.
