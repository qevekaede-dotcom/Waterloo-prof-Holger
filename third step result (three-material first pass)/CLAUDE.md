# Rules for this result package

Curated third-step deliverable: the three-material first-pass comparison for
Roy. Built from the authoritative records in `thermo_candidates/<material>/`.

- `READY_TO_ATTACH/` is **frozen**: the combined email was sent (this package
  as Folder 2, the second-step package as Folder 1). It records exactly what
  was sent; do not edit it. Any future submission goes in a new package.
- The authoritative raw/derived records live in the material workspaces; treat
  the copies here as read-only snapshots. If a number changes upstream,
  regenerate here rather than editing the copy.
- `WORKLOG.md` is append-only history. Add dated entries; do not rewrite past ones.
- Do not add large raw files (wavefunctions, charge density, `.bt2`, full logs).
- No dates in any file that might be sent to Roy; dates belong only in the log.
- Keep units in every data-column header.
- The experimental-vs-computational answer in `EMAIL_DRAFT.md` was supplied by
  the user in their own words and transcribed verbatim in tone; it was not
  invented. No placeholder remains.
