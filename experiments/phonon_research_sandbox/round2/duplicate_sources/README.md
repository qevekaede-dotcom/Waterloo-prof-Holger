## 最小后续检查：先看现成数据，不先重算

如果 Roy 选择 Rb 路线并另行授权一次有界的远端读取：

1. 只对这 11 个任务及 pristine，检查已保存输入与 manifest 哈希对应、结构/原子顺序、赝势、全部物理设置和执行健康。解释 pristine 来源哈希差异；不能未经检查就当作路径或格式差异。
2. 对确认等价且健康的子集提取最后一个完整主力块，比较逐原子力差的最大分量和 RMS；保持原始力不变，不先减平均值。若健康/等价性检查失败，就报告该子集不能作重复噪声估计。
3. 把结果作为**这些已有构型与运行条件下**的重复性诊断，不能自动推广到所有位移、未来超胞、振幅或温度。将它与已提议的力噪声标准比较，不新造通过标准。
4. 只有确认内容级构型与力计算合同等价，才讨论未来的“同构型只计算一次、按映射填入多个 displacement 条目”。必须保留每一个 phono3py 数据集条目和映射；不能从历史 YAML 删除重复条目，也不能把复用同一力制造成独立噪声样本。

可能收益是用已有数据先判断噪声，再决定是否需要新重复计算；资源收益尚未测量。没有自动复用、删除任务、提交新作业或保证节省核心小时。

## 复现

Python 需要 PyYAML（已有 thermo-bt2 环境可用）：

```bash
python3 experiments/phonon_research_sandbox/round2/duplicate_sources/analyze_sources.py
```

脚本仅读取两个保存文件，先校验 YAML 与 manifest 的 SHA-256 绑定，再按来源哈希分组并核对最大组的名义位移相消。不拟合 FC 或读取所有力输出。`source_sha256` 字段的生成可追溯到 [`prepare_force_firstpass.py`](../../../../thermo_candidates/Rb2Cu2SnS4/phono3py/prepare_force_firstpass.py)；原始生成文件当前未重新审计。
