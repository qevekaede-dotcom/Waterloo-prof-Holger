# 用本项目文件理解 QE → 力 → FC2/FC3 → 声子 → κL

这是本轮的精简导读，不是提交作业的脚本。读完每一节，先回答末尾问题再看下一节。

## 1. QE 计算的是电子基态，也给出原子受力

固定晶胞和原子坐标时，SCF 寻找自洽电子密度。原子力是能量对坐标的负导数：`F = −∂E/∂u`。有限位移法将一个或多个原子轻微移动，然后比较力的响应。

项目实例：[SrCu2SnS4 v2 campaign.json](../../thermo_candidates/SrCu2SnS4/phono3py_v2/campaign.json)。`ecutwfc`/`ecutrho` 控制平面波基组截断，电子 k mesh 控制布里渊区电子积分，`conv_thr` 控制自洽精度。它们都可能影响微小力差。电子能量看似收敛，不保证声子所需的力差已经可靠。

**检查自己：** 只把 `conv_thr` 调小，能否证明力已经收敛？不能，基组、k mesh、结构驻点等仍会影响力。

## 2. 力块存在、计算健康、力精度是三种不同证据

[共享解析器 qe_output.py](../../thermo_candidates/scripts/phono3py_campaign/qe_output.py) 读取最后一个 PWSCF run 的主力块。`verbosity=high` 还会输出分项力，不能把这些行拼进主力数组。最后一个正常写出的力块也不能覆盖后面的 MPI/QE 错误。

历史 SrCu2SnS4 pristine 是实际反例：它写出力块后又发生错误。`--cfz` 使用的力可追溯，但终态不健康。新软件修复拒绝 stdout 中的致命标志，并不使历史结果自动变好。

v2 还暴露了一个独立问题：输入哈希正确、提供的日志健康，仍不能证明二者属于同一次真实执行。需要可信 runner 在执行前绑定输入/命令/环境，再在执行后绑定输出/退出状态，记录外部审阅锚点。目前尚未实现这一执行链，本地报告会明确 `execution_provenance_verified=false`。

**检查自己：** `JOB DONE` 和完整力块是否足以验收？还要看进程退出、stderr、最终 run 的错误、SCF 完成及输入绑定；这些通过后也未必满足力精度和科学收敛。

## 3. FC2 与 FC3 描述不同阶的响应

在参考结构附近，能量展开为

`E = E0 + Σ gᵢuᵢ + ½ Σ Φᵢⱼuᵢuⱼ + ⅙ Σ Ψᵢⱼₖuᵢuⱼuₖ + …`

FC2 (`Φ`) 描述二阶能量曲率，决定谐波频率与振动形状。FC3 (`Ψ`) 描述三阶非谐耦合，可用于计算三声子散射。参考结构应接近驻点，即 `g` 接近零。减去 pristine 力能处理恒定偏移，却不能证明该结构已经是局部极小值。

[SrZrS3 保存审计](../../thermo_candidates/SrZrS3/phono3py/evidence/first_pass_unconverged/force_audit_summary.json) 中 FC2 为 `(40,40,3,3)`，FC3 为 `(40,40,40,3,3,3)`。每个 40 对应超胞原子索引，3 对应笛卡尔方向。形状和有限值通过只证明基本完整性；还没有回答超胞和截断是否足够。

**检查自己：** 为了定位 SrZrS3 虚频，是否必须先重跑全部 FC3？不必，先用 FC2-only 对照检验谐波问题更有针对性。

## 4. 电子 k mesh、声子 q mesh、超胞、pair cutoff 不能混用

| 参数 | 控制什么 | 本项目容易混淆的地方 |
|---|---|---|
| 电子 k mesh | QE 电子积分与力精度 | 不是后处理声子 q mesh |
| 超胞 | 有限位移响应的周期环境、可解析的实空间范围 | 改超胞就改变周期像，不能直接复制旧力 |
| FC3 pair cutoff | 省略哪些双位移组合以降低成本 | 历史 SrCu 的 4 是 bohr，不是 Å |
| 声子 q mesh | 对既定 FC2/FC3 的倒空间采样/积分 | 加密它无法修补缺失的长程力响应 |

[Rb 保存审计](../../thermo_candidates/Rb2Cu2SnS4/phono3py/evidence/firstpass_20260914/production/postprocess_22312417_hdf5_readonly_audit_20260920.json) 中 45–105 Å 是广义规则网格的密度长度参数。保存的 `mesh` 是 Smith-normal-form 网格信息的一部分，不能简单读成沿晶轴的三个采样数；需要实际 grid matrix/变换矩阵才能解释网格几何。

## 5. 虚频说明当前谐波模型出现负曲率，原因需要对照

动力学矩阵的负本征值常用负号频率表示。它可能来自参考结构、力误差、有限超胞或真实软模。本项目 SrZrS3 保存审计的最低值约 −1.0716 THz，不能因为文件里仍有有限 κ 值就忽略。

[SrZrS3 计划](plans/SrZrS3.md) 先复核结构与力精度，再比较 harmonic 超胞、振幅和模态。只有数值敏感性排查后，才有依据讨论本计算层级的物理不稳定；这仍不等同于真实有限温度材料必然不稳定。

## 6. κL 综合热容、群速度与寿命

RTA 中可直观理解为 `κᵅᵝ ∝ Σ Cλ vλα vλβ τλ / V`，求和及权重由 q 网格和实现定义。FC2 影响频率、热容和群速度，FC3 影响三声子散射与寿命。因此仅提高一个积分网格，无法弥补上游模型误差。

[Rb 全张量表](results/rb_qmesh_ladder_all_tensors.csv) 保留了各温度的 `xx, yy, zz, yz, xz, xy`。平均 `trace/3` 可以掩盖各方向变化。现有 Rb 程序对平均和各对角分量分别比较，所有温度连续两次转换通过才算 q 网格通过；这仍不是所有物理维度均收敛。

**一次可手算的例子：** 300 K 时，90 Å 的 zz 是 0.1224715416，105 Å 是 0.1363703426 W m⁻¹ K⁻¹。`|new−old|/new = 10.19195%`。当前分母是 new，不能改成 old 后仍称复现了原验收规则。近零非对角分量应报告绝对值/适当归一化量，不用巨大的相对百分数制造变化印象。

## 7. 最后才谈完整 zT

`zT = S²σT / (κe + κL)`。目前电子表报告 PF/τ，不能直接当作绝对 PF。已有电子-only zTₑ 不包含晶格热导；在同一输运模型和匹配载流子条件下它可作上界式诊断，但不是最终材料 zT。还缺 τ 模型、验收后的 κL，以及进一步电子输运性质收敛检查。
