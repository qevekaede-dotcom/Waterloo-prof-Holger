# SrZrS3：先解释虚频，再决定是否计算 κL

状态：**研究提案，不是执行授权**。2026-09-21 用户已确认把科学状态更新发送给 Roy；目前应等待 Roy 的方向。现有 -1.0716 THz 结果不能直接证明材料真实不稳定，也不能作为有效 κL 的输入。

## 科学问题

在 mp-558760、Pnma 结构上，q=[0,0.4,0] 附近的显著虚频是由非驻点结构、有限超胞/插值、力精度/位移振幅或真实 0 K harmonic 软模造成？只有先回答这个问题，才有理由投入 FC3 与更密 q 网格。

## 直接证据

- 788 个 array row 完成并通过输入/输出/映射/完整力块审计；FC2 `(40,40,3,3)` 与 FC3 `(40,40,40,3,3,3)` 有限值和对称/声学和残差诊断正常。这里的“正常”只证明文件/代数完整，不证明物理收敛。
- pristine 最大分量 9.342e-5 Ry/bohr，超过已有首选 5e-5 门槛；一次性 `<1e-4` 例外允许了诊断性后处理。这意味着参考结构尚未满足原定首选驻点门槛。
- 2×1×1、40 原子、3.5541348625 Å、0.03 Å、80/640 Ry、3×3×3、显式 no-NAC 的 12×5×3 网格给出最低 -1.0716026422440281 THz，q=[0,0.4,0]，并有 12 个采样模低于 -0.1 THz。
- 因 harmonic gate 失败，有限 κ 张量只保留为 rejected diagnostic，未运行更密 q 网格。

## 解释假设（按当前证据排序）

1. **最先排查：参考结构不是足够精确的驻点。** 这是唯一已有直接异常：pristine 残余力超过首选门槛。逐原子减 pristine 力能减少 FC 拟合偏置，却不能把非驻点结构变成真正局部极小值。
2. **高优先级未解决：2×1×1 harmonic 超胞的 IFC 空间范围。** 当前超胞只沿一个方向扩展；最低点位于非 Γ 的 [0,0.4,0]。现有证据尚不能判断有限超胞是否产生或放大该软模，必须在声称真实不稳定前做 FC2-only 尺寸对照。
3. **中优先级：有限位移振幅与 SCF/基组误差。** 六任务 pilot 证明信号远大于重复噪声，但没有做 0.02/0.03/0.04 Å 斜率比较，也没有证明软模频率对 80/640、3×3×3 稳定。
4. **中低优先级：极性长程项/no-NAC。** SrZrS3 是离子型候选，NAC 最终值得检查；但当前最负点不是 Γ 极限，因此 NAC 不是首先解释 [0,0.4,0] 软模的充分理由。
5. **最后才接受：真实 0 K harmonic 不稳定或存在更低能结构。** 只有在结构、力设置、振幅、FC2 超胞与必要 NAC 敏感性都稳定复现同一模态后，才能沿本征矢探索局部极小值。即使如此，也应称“本计算层级下的 harmonic instability”，不能直接外推有限温度相稳定性。

NIMS 有同一 mp-558760/Pnma 的独立 VASP/phonopy 数据，可作结构与模态对照，但不同结构弛豫、赝势和数值设置使它不能直接裁决本结果。

## 判据：已有门槛与提议门槛

已有项目门槛：

- pristine 最大分量首选 ≤5e-5 Ry/bohr；现有 9.342e-5 不通过。`<1e-4` 是历史一次性诊断例外，不是未来生产标准。
- harmonic gate：全网格小于 -0.1 THz 的显著模拒绝 κL；Γ 声学例外需要人工审阅。
- SrZr 后处理代码若未来获准继续 q 网格，会以当前（较密）网格值作分母，在 300/600/900 K 要求 trace/3 严格 `<3%`、最大对角分量严格 `<5%`，并连续两步通过；当前因首级 harmonic gate 失败而未进入该比较。
- 已有振幅 pilot 提案：重复 RMS ≤5e-6 Ry/bohr，中心斜率相对变化 ≤5%，混合二阶差分 ≤10%，信号/传播噪声 ≥10。

提议判据（须 Roy/课题组审阅）：

- FC2 超胞：最低 20 个非 Γ 模在共同 q 点的绝对变化 ≤0.05 THz，且可稳定配对的模相对变化 ≤5%；软模本征矢质量加权重叠 ≥0.9。近零频率不使用相对误差。
- 真实软模判定：至少两个更大 FC2 超胞、两个合格力设置/振幅组合都在相同 q 邻域复现 `<-0.1 THz`，且本征矢重叠 ≥0.9；随后在满足 `q·T∈Z` 的独立冻结模超胞中，以映射后的实 `±q` 组合做对称振幅与 relax，并显示更低能极小值。FC2 插值候选与冻结模相容超胞承担不同问题，不能混用。任一条件缺失时只写“未解决虚频”。
- 外部 NIMS 数据只用于对照：先确认晶型、晶格、原子顺序和计算层级，不设“必须一致”的接受阈值。

## 依赖、资源与停止条件

依赖顺序：Roy 确定是否优先处理 SrZrS3 → 离线 FC2 软模地图 → 驻点复核 → 小规模振幅/力设置 probe → FC2-only 插值超胞 → NAC 对照 → 核验 q/参考胞基与本征矢映射 → 冻结模相容超胞的 count-only/预算 → 实 `±q` 位移静态检查与条件式 relax → harmonic gate → 才考虑 FC3/κL。

资源依据：现有 FC3 生产有 788 个 array row，但这不是下一步预算模板。虚频问题首先只需 FC2，官方 phono3py 支持 FC2 与 FC3 使用不同超胞；应避免再次承担 787 个 FC3 位移。仓库未保存足以可靠外推新 60/120/200/320 原子 SCF 的完整 P90 计时，批准总 core-hours 也是 null。只有在 reference/q basis 核验成立后，冻结 q=(0,2/5,0) 的 1×5×1、100 原子才可作为最小对角相容几何示例；它不是已批准尺寸或成本估计。先 count-only 列出 ±分支、振幅、静态与可能 relax 数，再以 ≤6 个代表任务取得 P90 并用仓库公式估算；预算未批准不提交，不能先启动 relax 再补预算。

停止条件：pristine 仍未达门槛；Pnma/原子映射丢失；q 的参考胞/倒易基或超胞矩阵约定无法核验；冻结模不满足 `q·T∈Z`；无法从 `±q` 共轭对构造并复核实位移；振幅 probe 低于噪声；更大 FC2 超胞让软模位置/频率无规律漂移；候选超出已批准原子/任务/核心时预算；Born/介电张量或结构 provenance 不完整；任何新设置只能靠放宽既有门槛才能“通过”。这些情况均报告“未解决”，不自动升级到 FC3 或更密 q 网格。
