# Rb2Cu2SnS4：最大化力数据复用，先做物理收敛再加密 q 网格

状态：**研究提案，不是执行授权**。用户已在 2026-09-21 确认发送给 Roy 的状态更新，当前没有记录到回复。现有 HDF5 是 rejected diagnostic；不能因恢复任务成功或文件存在而宣称 κL 完成。

## 科学问题

现有 M72、3.70 Å、0.03 Å、680-task 力数据能够可靠支持哪些结论？怎样在不浪费这些已审计力的前提下，最小成本区分 q 网格未收敛与更上游的 FC2/FC3 物理未收敛？

## 已确认事实

- FIRE 与独立 pristine 结构门槛通过；现有生产使用 72 原子 M72、3.70 Å cutoff、0.03 Å 位移、100/800 Ry、2×2×2、`conv_thr=1e-10`、`nosym/noinv`。
- 恢复后完整 680-task force audit 通过；FC2 `(72,72,3,3)`、FC3 `(72,72,72,3,3,3)` 的保存 HDF5 通过形状、有限值、映射、版本和 18/72 原子绑定检查。
- 22312417 的非零退出来自包装器错误地要求 `fc3.hdf5/force_constants`；实际键是 `fc3`。这解释技术失败，不等于科学通过。
- 保存的五级 GRG HDF5 在 length-like 参数 45→60、60→75、75→90、90→105 Å 每一步都失败。最后一步 trace/3 变化约 4.27%、4.08%、4.05%，最大对角分量约 10.19%、9.69%、9.59%。这里的 Å 值是生成 GRG 的单个长度参数，不是三方向整数 q-mesh；105 Å 结果只是 rejected diagnostic。
- 七任务 pilot 支持当时 probe 上 2×2×2 相对 3×3×3、80/640 相对 100/800 与重复性门槛，但没有测试位移振幅、FC3 cutoff 或超胞收敛。

## 力复用边界

可以复用：

1. 同一 `phono3py_disp.yaml`、同一 M72/3.70 Å/0.03 Å、相同结构/赝势/QE 输入/原子顺序/版本且哈希完全一致时，复用已审计 FORCES_FC3、FC2、FC3 做离线诊断或 q 网格重算。
2. 现有单原子位移子集可用于同一 M72 的 harmonic FC2 分析；必须保留 pristine subtraction 与完整映射。
3. 较大 cutoff 的未来数据若严格包含较小 cutoff 的 displacement IDs，可从大向小派生；必须逐 ID 与哈希证明。

不能复用：

1. 3.70 Å 数据不能生成 4.25/5.00 Å 新增 pair 的力。现有预检显示同一 M72 分别需 1343/1811 个位移，缺失项不能用零填充后称为收敛。
2. M72 力不能用于 M108/M216，因为超胞原子数、周期像和位移响应不同。
3. 0.03 Å 力不能证明 0.02/0.04 Å 振幅不敏感。
4. 现有 q 网格失败不能通过改变 summary 脚本、只看 trace 或只报 105 Å 数值来“修复”。

## 排序后的解释假设

1. **直接证据：当前 q 网格本身未收敛。** 每个相邻步骤均失败，尤其 zz/第三主方向变化约 10%。
2. **更重要的未验证项：3.70 Å FC3 cutoff 可能过短。** 官方文档明确 cutoff 会牺牲 FC3 精度；现有数据没有更长 cutoff 对照。
3. **高优先级：M72 超胞不足以证明 FC2/FC3 空间范围。** harmonic stability 通过当前有限网格，只说明保存 FC2 没有显著虚频，不证明更大超胞不改变频率/κ。
4. **中优先级：位移振幅的有限差分偏差未测。** 重复噪声很小是好信号，但不能替代 0.02/0.03/0.04 Å 斜率比较。
5. **后续模型项：no-NAC、RTA、无同位素/边界散射。** 这些会影响最终解释，但应在 FC2/FC3 数值收敛后检查。

## 正确顺序：物理收敛优先于更密 q 网格

```
现有力/FC 完整性
    ↓
振幅与力精度 → FC2 超胞/稳定性
    ↓
FC3 cutoff → FC3 超胞
    ↓
固定 FC 后才继续 q 网格
    ↓
NAC、RTA/LBTE、同位素等模型敏感性
```

理由：q 网格只对既定 FC2/FC3 做倒空间采样。即使更密网格最后满足代码的严格 `<3%`/`<5%` 规则，也无法证明 3.70 Å cutoff、M72 或 0.03 Å 产生了正确的力常数。

## 判据：已有门槛与提议门槛

已有项目门槛：

- Rb 当前代码在 300/600/900 K 全部使用当前（较密）网格的正对角值作分母：`abs(current-previous)/current`；trace 使用 `abs(sum(current-previous))/sum(current)`。每个温度的 trace/3 必须严格 `<0.03`，最大对角分量必须严格 `<0.05`，且连续两步通过；off-diagonal 必须报告。当前所有步骤失败。
- harmonic gate：全网格 `<-0.1 THz` 的显著模拒绝 κL；Γ 声学例外人工审阅。现有只读审计的最低值约 -1.4e-7 THz，通过这一有限检查。
- 力差 pilot：最大分量 ≤5e-5、RMS ≤1e-5 Ry/bohr、相对 RMS ≤2%、重复 RMS ≤5e-6，全部通过。
- 当前资源配置中 `approved_total_core_hours_per_material` 为 null；没有生产授权。

提议判据（须审阅）：

- 振幅：中心一阶斜率相邻振幅变化 ≤5%，混合二阶差分 ≤10%，信号/传播噪声 ≥10；低于分辨率改 probe，不判通过。
- harmonic 超胞：最低 20 个非 Γ 模绝对变化 ≤0.05 THz，稳定配对模相对变化 ≤5%，本征矢重叠 ≥0.9。
- FC3 cutoff 与超胞：提议在固定中等 q 网格上移植同一严格 `<3%` trace / `<5%` 对角规则，并分别以当前较大 cutoff/超胞一级作分母，要求两次连续物理跃迁都通过；这是物理收敛的提议用法，区别于已在 Rb q 网格代码中实现的规则。最低可判定序列是 `C0,C1,C2` 或 `S0,S1,S2`；单次 `C0→C1` 或 `S0→S1` 通过只算 pilot。若第一步失败，第三点不会自动构成两次连续通过，需根据结果继续选择下一级或诚实结束为“资源限制下未收敛”，不可降低门槛。
- q 网格下一点不预先指定为“最终”；由实际 reciprocal spacing、整数 GRG 与相邻张量变化决定。

## 依赖、资源与停止条件

依赖顺序：Roy 方向 → 离线现有数据收口 → ≤6 个计时/噪声子集 → 完整振幅科学矩阵 → FC2 超胞 → FC3 cutoff → FC3 超胞 → q 网格 → 模型敏感性 → 报告。

资源依据必须来自数据而非猜测：M72/3.70 Å 已知是 679 位移加 pristine；M72/4.25 Å 和 5.00 Å 的 count-only 分别为 1343 和 1811 位移，但这两点只提供成本信息，不自动规定 `C1/C2`。M108 新数据未在本轮核实生产计时，也不自动规定 `S1`。已有 `%32` 是调度节流，不是 32 总核心，也不是未来容量保证。先以最多 6 个任务量出 P90 walltime/MaxRSS/SCF iterations；这只是资源子集，不能替代至少 24 个单原子位移 SCF 的完整四元素、三振幅、正负号科学矩阵。cutoff 和超胞在首个候选生产前都要把“基线 + 第一候选 + 可能的条件式第二候选”纳入任务数与预算包络；第二候选仅在第一跃迁审阅后选定、count-only 并另行放行，不预启动。若预算只够一次跃迁，交付物只能是 pilot/未收敛。之后才用仓库公式估算完整候选 core-hours；预算 null 或超额即停。

停止条件：任何 force/dataset/hash/atom-order 复用条件不满足；振幅低于噪声或明显非线性；更大 FC2 发现显著虚频；cutoff/超胞无法取得两次连续通过；包含条件式第二候选的 count-only/预算包络超过批准任务或核心时；q 网格新增一级后内存/时间超预算；NAC 数据 provenance 不完整；Roy 未授权所需计算。停止结果应写明“现有力可复用到哪一步”和“哪个物理维度仍未收敛”。
