# SrCu2SnS4：从 v2 输入边界到可判定的物理收敛

状态：**研究提案，不是执行授权**。2026-09-21 已由用户确认向 Roy 发送科学状态更新；仓库没有 Roy 回复。应先等待 Roy 指定优先级，再申请任何 QE/phono3py/Slurm 工作。

## 科学问题

在统一、可追溯的力输入合同下，SrCu2SnS4 的 FC2/FC3 与 RTA 晶格热导是否对结构驻点、位移振幅、超胞、FC3 pair cutoff、力计算设置和 q 网格达到足以报告的收敛？历史值只能回答“旧配置产生了什么”，不能回答 4 Å 截断或物理收敛问题。

## 已确认事实与未解决项

v2 已修复或强制：

1. `unitcell.in` 的生成路径已纠正；QE 模式中的 4.0 Å 明确转换为 7.5589045 bohr。
2. pristine 与全部位移统一为 90/720 Ry、3×3×3、固定占据、`conv_thr=1d-09`、`nosym=.true.`、`noinv=.true.`、96 原子。
3. 生成器路径/哈希/版本、四个赝势哈希、数据集语义、输入哈希、外部保留 manifest anchor 和 pristine-health anchor 均被记录并相互核验。当前实现会拒绝它显式检查的 `RUN_DIR`、health/evidence 与 pseudo 路径中的符号链接和已覆盖记录；这是有范围的防护，不代表任意路径或所有重绑/覆盖方式都已被普遍证明安全。
4. 默认仅 dry run；没有 Slurm 模板，QE、提交、后处理全部未释放。
5. 2026-09-21 的本地工具修复把 pristine `scf.in` 的精确字节哈希和 96 原子合同绑定到审阅过的 manifest，在写 health evidence 前拒绝被替换的当前输入；manifest 也新增 `dataset_semantics.py` 哈希，preflight 会重验该验证器。这证明当前输入完整性，但还不证明某份 QE 输出确由该输入运行得到。
6. 共享 QE 解析器现会把最终 PWSCF stdout 中位于完整力块或 `JOB DONE` 之后的 fatal signature 判为不健康，避免重演历史 pristine 的“有力块但终态异常”误判。

仍未解决：

1. v2 尚未生成真实数据集，也没有健康的 pristine QE 结果、位移力、FC2/FC3 或 κL。
2. 2×2×1、0.06 bohr（约 0.03175 Å）和 4.0 Å 只是起始假设；超胞、振幅、pair cutoff 均未收敛。
3. 90/720 Ry 和 3×3×3 是历史力差证据支持的合同，不是新 v2 全数据集收敛。
4. NAC、显式 SOC、同位素/边界散射与 q 网格收敛都未包含。
5. 历史 pristine 在写出完整力块后发生 `seqopn(90)`/MPI abort；历史力块可追溯，但不能作为健康 pristine 的先例。
6. **执行来源尚未证明。** 当前审计分别核验 manifest 中的精确输入哈希，以及调用者提供的 stdout、stderr、exit-code 证据；仓库尚无执行时生成的 receipt 把两者绑定为同一次 `pw.x` 运行。因此当前状态应记为 `execution_provenance_verified=false`。在任何真实 v2 执行或结果接受前，未来协议必须 fail closed 地记录并核验输入摘要、实际命令与可执行文件/版本、工作目录与环境、作业/运行标识、stdout/stderr 目标、开始/结束时间、退出码和不可变证据位置；本计划不新增运行器。

## 排序后的解释假设

1. **直接证明：历史 FC3 只纳入零距离 pair。** 原始 YAML 的长度单位是 au，4.0 实为 4 bohr；所有被纳入 pair group 的 pair distance 为零，最近非零 pair 被排除。历史 FC3 因而近似 onsite-only。它对历史 κL 数值的影响大小、是否为主导误差来源都尚未证明，必须用更长 cutoff 对照。
2. **高优先级未解决：2×2×1 超胞的力常数空间范围。** 官方方法说明有限超胞会周期复制位移响应；当前没有相邻更大超胞对照。因此只能说“尚未证明充分”，不能预判该超胞一定不足。
3. **可能：位移振幅与力噪声/非线性平衡未验证。** 0.03175 Å 处于常见量级，但“常见”不等于本材料收敛。
4. **可能：历史混合 90/720 与 60/480 Ry 设置污染一致性。** v2 已消除输入混用，但尚未用真实计算证明修复后的科学影响。
5. **次要但最终必须检查：q 网格、NAC、RTA 与 SOC 会改变最终解释。** 它们应在 FC2/FC3 上游收敛之后检查，不能补救截断 FC3。

## 判据：已有门槛与提议门槛

已有项目门槛（沿用但不宣称普适）：

- pristine 最大力分量首选 ≤5e-5 Ry/bohr；`JOB DONE`、SCF 收敛、完整 96 原子主力块、零进程退出和干净 stderr 必须同时满足。
- 历史 SrCu 只使用“最终平均值变化约 3%”的平均量检查；它没有实现 Rb 代码中的严格逐温度、逐对角、连续两步规则，不能倒写成历史已通过的门槛。
- force-setting pilot 的已有量级门槛：最大分量差 ≤5e-5、RMS 差 ≤1e-5 Ry/bohr、相对 RMS ≤2%，且全部通过。

提议判据（须科学审阅后采用）：

- 振幅：0.02↔0.03 与 0.03↔0.04 Å 的中心一阶斜率变化 ≤5%，混合二阶差分变化 ≤10%，信号至少为传播后重复噪声的 10 倍；与现有其他材料 campaign 的 pilot 规则一致，但 SrCu 尚未验证。
- harmonic 超胞：选定非 Γ 软模/最低 20 个频率中绝对变化 ≤0.05 THz 且相对变化 ≤5%；接近零频率只用绝对判据。本条是新提议，不是仓库既有验收阈值。
- cutoff 与 FC3 超胞：提议移植 Rb 的代码规则，即在固定 q 网格下使用当前（较大 cutoff 或较大超胞）一级作分母，要求每个温度的 trace/3 变化严格 `<3%`、每个对角分量严格 `<5%`，并要求两次连续物理跃迁都通过；这是 SrCu 的新提议，不是 SrCu 历史实现。`C0→C1` 或 `S0→S1` 单次通过只算 pilot；最低可判定序列为 `C0,C1,C2` 或 `S0,S1,S2`。若第一跃迁失败，则继续的候选数由实际变化和预算决定，不能把第三个固定尺寸盲定为终点。
- NAC：只作为最终敏感性分支；没有 Born/介电张量时报告 no-NAC，不用经验参数替代。

## 依赖、资源与停止条件

依赖顺序：Roy/课题组确定优先级 → v2 数据集生成与 semantic/count-only → 审阅 execution-receipt 协议 → receipt 可验证同一次执行的精确输入与进程证据 → 独立健康 pristine 与 anchors → 完整 preflight 重放 → 振幅/力设置 pilot → FC2 超胞 → FC3 cutoff/超胞 → q 网格 → NAC/模型敏感性 → 报告。

资源只按实测估算。历史保存的 4982、3074、2521 s 是三个代表性 96 原子任务，不覆盖新超胞或全数据集；不能外推出可信总 core-hours。每个候选先做 ≤6 个计时/噪声任务，记录 elapsed、MPI ranks、MaxRSS、SCF iterations 和失败率，再用 `remaining_tasks × max(1.5×P90 walltime, 正常最大 walltime) × MPI ranks` 报预算。cutoff 与 FC3 超胞在首个候选生产前都要把“基线 + 第一候选 + 可能的条件式第二候选”纳入任务数和预算包络；第二候选只在第一跃迁审阅后选择、count-only 并另行放行，不预启动。若预算只够一次跃迁，交付物只能是 pilot/未收敛。预算未批准则不进入 production。

立即停止并回到审阅的条件：execution receipt 缺失或不能把精确输入与进程证据绑定；结构/pristine 门槛失败；真实 YAML 单位/截断壳层与计划不符；pilot 信号低于噪声；候选 displacement 数或包含条件式第二候选的预算包络超过批准值；出现非 Γ 显著虚频；连续物理跃迁仍不收敛；任何输入/赝势/数据集/证据哈希漂移。停止时保留失败证据，不自动改参数重跑。
